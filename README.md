# Candidate-Election-Guide-System
About: 
  The Candidate Election Guide System was made to inform voters to make wiser decisions by means of showing information on candidates running for positions.      Furthermore, the program also facilitates voting and keeps tally, ensuring no third parties rig or change votes.

Requirements for usage:
  1. The user must have the file downloaded in order to run it, with sufficient storage to run the program
  2. To login to the program, the user must be at the age of 18 or above, whether a voter or administrator.
  3. The user must be able to input their birthday for the program to double check that they are at or above the age of 18.
  4. If the user is a voter, they must have appropriate knowledge and perspective about the qualities, traits, and characteristics of the leader they prefer.
  5. If the user wishes to select being an administrator, they must be at the age of 30 years old or above to make sure they are old enough to access the system of the voting list.
  6. Apart from age checking, to ensure that the user is really an administrator, the username “admin”, along with the specific numerical password, “123”, is needed to solidify their identity to the program as an administrator.

Features throughout the program:
Log-in Page - Allows the user to log in or sign up as either a voter or administrator. It will include a checking system where only users that are 18+ years old are allowed to log in or sign up.
Security - The program will ask the user for their birth date to ensure that they are an adult, double checking their right and eligibility to vote or not. After the user verifies that they are old enough to vote, the program asks if they are an administrator or a voter.
Main Page - This part will contain options where the user can choose to either vote, view the candidate information lists, or answer the candidate compatibility survey.
Candidate Information List - Users are able to view the traits, programs, and slogans of each candidate. A separate list can also be chosen to view the candidate’s history in the government if applicable.
Administrator Rights - Before verifying that the user is an administrator, the program first asks whether they are 30+ years old, as users of the age 29 and under are not allowed to access the vote list. After this is verified, a specific password for admins will be asked from the user before giving them access. When a user is confirmed to be an administrator, they are allowed to access the candidate information list and edit it. With this, it is ensured that the lists are always up to date based on the latest voter.
Candidate Compatibility Survey - Gives the users an idea of which candidates are most compatible to their standards. This feature can also help them figure out which candidate they should vote for based on their opinions and preferences for a leader, if they are unsure.

Usage:
Please read the program's prompts carefully, and choose the corresponding number to the option you would like to be followed through with. It is crucial that the user inputs the numerical shorthand—otherwise, the program will end abruptly, which applies for both user and admin.
